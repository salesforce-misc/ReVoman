= Get Started

Wire ReṼoman into your JVM project, then run your first API-Graph against a deterministic local
real-wire handler using ReṼoman's public `MockHttpServer`.

== Artifact

[.lead]
Maven
[source,xml,subs=attributes+,tabsize=2]
----
<dependency>
    <groupId>com.salesforce.revoman</groupId>
    <artifactId>revoman</artifactId>
    <version>{revoman-version}</version>
</dependency>
----

[.lead]
Bazel
[source,bzl,subs=attributes+]
----
"com.salesforce.revoman:revoman"
----

[.lead]
Gradle Kts
[source,kts,subs=attributes+]
----
implementation("com.salesforce.revoman:revoman:{revoman-version}")
----

[.lead]
Minimum Java Version required = 25 (0.90.x is the last line that runs on JDK 21)

== A Simple Example

Here is a simple exported Postman collection and Environment JSON file for a deterministic local
real-wire handler. You can import the same metadata and manually test it through the `Run
collection` button:

image::resfulapi-dev-pm.png[]

You can automate the same with ReṼoman by supplying the metadata and environment paths. ReṼoman
ships `MockHttpServer`; `DeterministicMockApi` is this repository's application-specific example
handler. The example below explicitly owns the handler and server, injects the server URL, and then
executes the API metadata (serialized in the Postman V2 schema) directly on the JVM:

[source,java]
----
import com.salesforce.revoman.integration.testsupport.DeterministicMockApi;
import com.salesforce.revoman.testing.http.MockHttpServer;
----

<1> `revUp` is the method to call passing a configuration, built as below
<2> Supply an exported Postman collection JSON file path
<3> Supply an exported Postman environment JSON file path
<4> Assert that the execution doesn't have any failures
<5> Run more assertions on the xref:rundown.adoc[Rundown]

`MockHttpServer` is a test-only listener bound to an ephemeral IPv4 `127.0.0.1` address. It records
request bodies in memory so you can inspect what ReVoman sent without calling a real HTTP service.
Handlers may run concurrently, so mutable handler state must be thread-safe.

Next, see xref:configuration.adoc[] for how you build that configuration through
`Kick.configure()`, and xref:rundown.adoc[] for the structured result the engine hands back.
